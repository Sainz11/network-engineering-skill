# Device Acceptance Workflow

1. Match device to work order and inventory.
2. Identify exact model/revision and obtain datasheet.
3. Choose the matching QC checklist.
4. Use isolated bench setup where possible.
5. Run only authorized tests; preserve existing provisioning.
6. Record raw results and evidence.
7. Assign PASS/FAIL/NEEDS REVIEW with reason.
8. Label and segregate failed/uncertain devices.
9. Produce handover report.
