# Incident Triage

1. Confirm scope, start time, affected services/customers, and recent changes.
2. Check power, physical link, interface state, and alarms.
3. Check VLAN/L2 path, MAC learning, STP, and port counters.
4. Check IP, DHCP, ARP/ND, gateway reachability, routing, and MTU.
5. Check DNS, NAT/firewall, PPPoE/IPoE, and upstream reachability.
6. For WLAN/radio, check association, RF metrics, channel utilization, retries, and both endpoints.
7. Compare with baseline and isolate one variable at a time.
8. Escalate with timestamped evidence and impact.
9. If a change is needed, follow change-control and rollback procedure.
