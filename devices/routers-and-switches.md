# Routers and Switches

## Router checklist
Model/revision; CPU/RAM; interface rates; WAN type; LAN/VLAN map; routing; DHCP/DNS; NAT/firewall; VPN; QoS; failover; monitoring; backup; firmware lifecycle.

## Switch checklist
Port map; access/trunk/native VLAN; STP root/edge/guard; LACP; SFP optics; PoE budget/class; MTU; LLDP; errors/discards; loop detection; management ACL; firmware.

## Common fault domains
Wrong VLAN tagging, duplicate IP, DHCP exhaustion, routing asymmetry, MTU mismatch, duplex/speed mismatch, bad optics/cabling, STP block, LACP mismatch, PoE budget exhaustion, CPU saturation.
