# Switch QC

- [ ] Model/revision, PSU and PoE budget verified
- [ ] Chassis, ports, fans, SFP cages inspected
- [ ] Boot and management access pass
- [ ] Copper ports link-test at supported speeds
- [ ] SFP/SFP+ tested with compatible optics and approved loopback
- [ ] VLAN access/trunk test in isolated lab
- [ ] STP/LACP/LLDP behavior checked where supported
- [ ] PoE output tested with compatible load and budget monitored
- [ ] Counters/errors/temperature/alarms recorded
- [ ] Backup and report saved
