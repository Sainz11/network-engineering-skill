# Outdoor Radio QC

- [ ] Exact model, hardware revision, band and antenna verified
- [ ] Enclosure, RF connectors, radome, mounting and cable inspected
- [ ] Approved power/PoE source verified
- [ ] Boot and management access pass
- [ ] Firmware/regulatory profile recorded
- [ ] Ethernet link and counters pass
- [ ] Radio interface and test association/link pass in controlled setup
- [ ] RSSI/RSL, SNR, noise, modulation/MCS, retries and utilization recorded
- [ ] PTP/PTMP/bridge/VLAN function tested as applicable
- [ ] Throughput/latency/loss tested against defined target in lab/approved window
- [ ] Grounding/surge protection evidence checked by qualified personnel
- [ ] Report and final status recorded
