# Router QC

- [ ] Model/revision and power adapter verified
- [ ] Enclosure, ports, reset button and LEDs inspected
- [ ] Boot completes; no unexpected alarm
- [ ] Management access works
- [ ] CPU/RAM/storage/temperature checked where exposed
- [ ] Each Ethernet port link-tested at supported speed
- [ ] DHCP, static IP, routing, NAT, DNS and VLAN tested in lab as applicable
- [ ] Wi-Fi tested only if device includes WLAN
- [ ] Config backup/export completed where authorized
- [ ] Results recorded with PASS/FAIL/NEEDS REVIEW

Use exact hardware specifications. Example: do not fail a Fast Ethernet model for not negotiating at 1 Gbps.
