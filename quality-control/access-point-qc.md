# Access Point QC

- [ ] Model/revision, mounting kit and PoE source verified
- [ ] Enclosure, antenna/radome and Ethernet inspected
- [ ] Boot and controller/cloud adoption pass
- [ ] Management reachable
- [ ] SSID and security test profile works
- [ ] VLAN/DHCP client test passes
- [ ] Radio bands/channels match model/regulatory domain
- [ ] Client association and basic throughput tested
- [ ] PoE draw and switch budget recorded where measurable
- [ ] Firmware/config backup and report recorded
