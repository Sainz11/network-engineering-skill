# ONT / Modem QC

- [ ] Exact model, revision, power adapter and PON/DSL/cellular type verified
- [ ] Enclosure, optical connector, LAN/WAN ports inspected
- [ ] Boot and LED/alarm state recorded
- [ ] Management access works
- [ ] PON/DSL/cellular registration checked in authorized lab/operator context
- [ ] Optical/line metrics compared with exact model/operator limits
- [ ] LAN ports tested at supported rates
- [ ] WAN/bridge/router/DHCP/PPPoE/VLAN tested only with approved test profile
- [ ] Wi-Fi and remote management checked where applicable
- [ ] No production provisioning erased
