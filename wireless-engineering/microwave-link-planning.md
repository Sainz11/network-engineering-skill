# Microwave Link Planning

1. Confirm endpoints, coordinates, elevation datum, antenna heights, and site permissions.
2. Confirm spectrum authorization, frequency pair, channel width, polarization, and emission limits.
3. Generate path profile; inspect LoS, Fresnel clearance, terrain, buildings, and vegetation.
4. Select equipment/antenna and calculate path loss, RSL, fade margin, and availability using current vendor tools and applicable engineering recommendations.
5. Review modulation/ACM, ATPC, XPIC, protection, capacity, sync, and interface handoff where supported.
6. Review grounding, surge protection, power, environmental ratings, cable/connector loss, and maintenance access.
7. Define acceptance thresholds from contract, vendor spec, and design; do not invent universal values.
8. Document as-built parameters and baseline alarms/counters.

Cambium LINKPlanner is one example of an official planning tool; equivalent vendor tools should be used for other platforms.
